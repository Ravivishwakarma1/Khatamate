01 Executive Overview & Core Architecture

Core Architecture

KhataMate (KhataFlow) is a state-of-the-art, multi-lingual, offline-first digital ledger web application engineered for small business owners, micro-merchants, retail shopkeepers, and service providers. It empowers users to record daily credit (Udhar) and payment (Jama) transactions seamlessly with zero internet dependence while ensuring multi-device cloud synchronization when connectivity is available.

ℹ️
Zero Downtime Offline Guarantee: All customer profile creations, transactions, and ledger entries write instantly to local browser IndexedDB storage before queued sync. The application remains fully functional even in deep rural internet dead zones.
1. Offline-First IndexedDB Engine lib/db/idb.ts
Utilizes client-side IndexedDB database via the idb library. Stores customer profiles, full itemized transaction histories, shop preferences, and pending sync queues locally.
  • Instant optimistic state updates with zero latency
  • Auto-reconciliation upon internet restoration
  • Local transaction search and calculation engine
2. Dual Cloud Sync Layer lib/db/sync.ts
Combines Supabase SSR PostgreSQL backend for persistent server state with Firebase Realtime Database for live multi-device session updates.
  • Background conflict resolution and timestamps
  • Real-time multi-device ledger mirroring
  • Multi-user role permissions (Owner, Manager, Staff)
3. Multi-Lingual Engine (8 Languages) i18n.ts
Powered by next-intl with localized dictionaries in messages/*.json. Offers seamless on-the-fly switching without app reloads.
  • English, Hindi (हिन्दी), Bengali (বাংলা)
  • Gujarati (ગુજરાતી), Marathi (मराठी), Punjabi (ਪੰਜਾਬੀ)
  • Tamil (தமிழ்), Telugu (తెలుగు)
4. App PIN Lockscreen Security lib/pin.ts
Protects customer credit records from unauthorized physical access using a 4-digit security PIN.
  • Local cryptographic hash check
  • Session auto-lock on inactivity or app switch
  • Quick PIN change & lockscreen test simulator in Settings

03 Customer Passbook & Advance Wallet Engine

Financial Logic

Customer Passbook Ledger app/[locale]/passbook/[id]

The Passbook view mimics a traditional paper khata book while providing modern digital audit trails. It presents a live running balance, chronological timeline of every transaction, and per-entry controls.

Advance Wallet & Overpayment Calculation Engine lib/finance.ts

KhataMate implements a dual-balance accounting equation for every customer profile: Net Balance = Outstanding Due - Advance Balance

  • Automatic Advance Offset on Credit: If a customer with an advance balance makes a new purchase (Udhar), the system automatically deducts from the advance wallet first before increasing outstanding dues.
  • Overpayment Allocation on Jama: If a customer pays more than their outstanding dues, the remaining excess payment is automatically allocated to their advance wallet.
  • Immutable Historical Audit: Each transaction records exact snapshot values for balance_before and balance_after.

Transaction Types Supported

Type Code Label Financial Impact Description
CREDIT Udhar Given + Outstanding Itemized goods/services sold on credit to customer
PAYMENT Jama Received - Outstanding Cash, UPI, Cheque or Bank payment received from customer
ADVANCE Prepaid Jama + Advance Wallet Customer pre-deposits money for future purchases
WRITEOFF Bad Debt Write-off Clears Due Uncollectable loss written off as bad debt expense
ADJUSTMENT Manual Adjustment ± Balance Corrective accounting entry for audits or discounts

04 Specialized Transaction Engines & Modals

Feature Deep Dive
1. Itemized Credit Modal AddCreditModal.tsx
Add detailed credit purchases with rich media & interest calculation.
  • Itemized rows: Item name, quantity, unit price & auto subtotal
  • Photo attachments: Capture/upload bill receipt photo
  • Voice note recording: Record verbal agreement audio
  • Interest engine: Simple/compound monthly or annual % calculation
  • Payment Promise Date picker with automated overdue alerts
2. Payment Jama Modal RecordPaymentModal.tsx
Record incoming payments with payment mode classification.
  • Multi-mode options: Cash, UPI, Bank Transfer, Cheque
  • Reference number: Store UTR, transaction ID or cheque no.
  • Early settlement waiver / discount handling
  • Automatic advance wallet overflow allocation
3. Dynamic UPI QR Code CustomerQrModal.tsx
Generates an on-demand UPI payment QR code dynamically populated with the customer's exact balance due and shop's UPI VPA.
  • Compatible with PhonePe, GPay, Paytm, BHIM
  • Instant scan & pay on shopkeeper's phone screen
4. Printable Bill Slip BillSlipModal.tsx
Creates mini thermal-receipt style digital tax invoices.
  • Shop header, GST details & customer room ID
  • Itemized item table with total tax breakdown
  • One-click thermal printer output & WhatsApp sharing
5. Official Legal Demand Notice LegalModal.tsx
Generates formal Legal Notice / Demand Letters for chronic defaulters.
  • Includes statutory interest clause & response deadline
  • Itemized transaction timeline attachment
  • Print-ready legal document format
6. Transaction Dispute Engine DisputeModal.tsx
Resolves buyer-seller ledger discrepancies gracefully.
  • Mark entry as "Under Dispute" with audit notes
  • Freezes disputed amount until mutual resolution
7. Bad Debt Write-Off WriteOffModal.tsx
Write off uncollectable debt (Nuksan) transparently.
  • Reason tagging: Customer moved, Bankruptcy, Disputed settlement
  • Reduces active outstanding while maintaining audit logs
8. WhatsApp Reminders SendReminderModal.tsx
Dispatch localized WhatsApp payment reminders.
  • Templates: Polite English, Friendly Hindi, Urgent Request
  • Automated wa.me deep links with pre-filled text
